<h1 align="center">脉络 Mailuo</h1>
<p align="center"><strong>看清所有安排，掌握每件事的进展。</strong></p>
<p align="center">将安排、执行与总结放在同一个个人工作台。</p>

脉络是一款支持 Docker 私有部署的个人工作台。将零散事项集中整理，简单的事直接处理，复杂的事逐步拆解；在工作台查看安排，执行中记录时间、等待和跟进，再回顾一段时间的投入与完成情况。

**当前发行：Community 社区测试版 `0.1.0-beta.1` · Linux x86_64 / amd64。**

本仓库是社区版的安装与反馈入口，公开发行配置和文档，**不包含应用源码，不代表应用已经开源**。镜像由阿里云公开仓库提供，安装不需要仓库账号。

## 能做什么

- **集中看安排**：今日待办、逾期事项及日历，查看当前关注与整体计划。
- **逐步推进事情**：事项、阶段、子任务与模板，简单记录后再逐步完善。
- **把等待记下来**：记录需要等待的人或条件，以及下一次跟进安排。
- **记录真实投入**：任务计时与实际耗时记录。
- **回顾执行情况**：按周期查看完成情况、时间分布与事项任务结构。
- **自己掌握数据**：Docker 私有部署，数据库与实例密钥保存在自己的设备。
- **电脑与手机浏览器使用**：响应式网页；目前不提供原生手机应用。

## 快速安装

1. 下载根目录 [docker-compose.yml](docker-compose.yml)，放到自己的项目文件夹。
2. 在极空间 Docker → Compose 中选择这份已有文件，创建/部署项目。普通 Docker 环境也可在该文件夹执行：

```bash
docker compose up -d
```

3. 等待 `app`、`postgres` 健康。`init`、`migrate` 正常退出码为 0，无需保持运行。
4. 查看 `init` 日志中的初始化码，访问 `http://你的设备IP:9000`，设置自己的账号和密码。

```text
mailuo/
├── docker-compose.yml
├── data/                # PostgreSQL 数据
└── secrets/             # 数据库密码、实例密钥及初始化码
```

使用 `./data`、`./secrets` 相对目录挂载，没有写死 NAS 路径。目录由 Compose 按实际配置文件位置解析；在极空间选择已保存的文件，避免编辑另一份配置。**修改挂载后要重新部署/创建容器，仅重启不会应用新的挂载。**

## 测试版边界

- 仅提供 `linux/amd64`，适用于 64 位 Intel/AMD（例如 Intel N5105），暂不提供 ARM。
- 每个社区实例目前提供一个本地账号，不提供公共注册、A5 管理后台或授权激活界面。
- 外部日历为基础单向排期推送，兼容性取决于日历服务商；不承诺所有第三方日历可用。
- 开发者信息是站内消息，不是手机系统推送，也不会自动升级。
- 建议先使用非关键事项试用，并定期备份。忘记密码目前需要部署者维护，没有邮件找回。
