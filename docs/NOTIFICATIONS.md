# 开发者信息订阅

偏好设置提供“接收版本更新提醒”和“接收开发者公告”。首次初始化以及从未保存过选择的设置页面默认勾选，用户可取消或保持；创建账号/保存时确认选择。已有关闭或单频道选择不会被升级覆盖。

这是站内消息，不是手机系统推送，不会自动升级。首次确认后尝试同步，之后约每24小时检查，亦可手动检查；断网不影响基础事项管理。

## 登记内容

向开发者接收地址https://stats.xtansuo.com登记：

- 与持久化实例密钥关联的独立实例ID、公钥、签名及请求序号；
- 当前软件版本、两个订阅选择、说明版本与确认时间。

接收方记录首次登记、最近联系时间和当前订阅状态，用于提供消息和统计去重订阅实例。该订阅协议不上传账号名、邮箱、用户ID、登录次数、登录IP、事项、日历或等待正文。网络访问本身仍可能在服务器访问日志留下来源IP，不能因此声称完全匿名。

一个实例同时订阅两项只计一个订阅实例，这不是全部装机量或用户人数。

## 取消与保留

在偏好设置取消后，本地立即生效并尝试同步撤回。离线时可能暂为待同步，恢复后重试；接收方确认全部取消后不再计入订阅数，客户端不再定期检查。停止联系90天后清理登记或取消墓碑。

部署者可设置app环境变量`MAILUO_OFFICIAL_DISABLED: "1"`暂停开发者信息联网；这属于维护开关，不能替代正常取消同步。

## 与旧版使用统计分开

以上订阅不会启用旧行为统计。新安装不默认采集登录次数、登录IP或活跃行为；已有旧版明确开启统计的用户，设置中保留折叠的关闭入口。旧统计维护开关为`MAILUO_TELEMETRY_DISABLED`，与通知订阅分开。

关于登记删除或相关问题，可通过项目Issues或[开发者网站](https://xtansuo.com)联系，请勿公开私人事项或密钥。
