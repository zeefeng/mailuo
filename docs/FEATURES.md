# beta.2 功能说明：脑图与全局背景

更新日期：2026-11-04。

> 本页功能包含在 Community `0.1.0-beta.2` 中。旧版用户应先备份，使用匹配的新版 Compose 执行增量升级。

## 事项脑图

事项梳理提供脑图与原列表切换。脑图显示当前筛选的事项数量和已展开数量，每个事项独立一行，按需展开阶段与子任务，不同事项用颜色区分，分支以曲线连接。

点击事项、阶段或任务的名称，打开当前视口内的悬浮编辑面板；点击卡片空白展开或收起已有分支。配置按内容分组，保存和取消始终可见，必要滚动只在面板内部进行，关闭后保留原来的查看位置与展开状态。

## 新增与拆解任务

- 事项上可添加阶段和任务。
- 任务下方“添加后续任务”用于新增同级任务。
- 任务右侧“＋ 子任务”用于进一步拆解，可继续添加下一层。
- 收起某分支会隐藏全部后代，再次展开先显示直接下一层。

父任务完成不会自动完成子任务，计划时间与投入仍逐任务记录。删除父任务时，直接子任务提升一级，不随父任务删除。

## 缩放与概览

脑图支持25%–200%缩放、恢复100%及适应窗口。电脑可在画布内使用Ctrl/⌘加滚轮；双击画布空白适应当前已展开内容，不新建事项。缩放仅影响脑图，工具栏与悬浮编辑面板保持原尺寸，刷新后回到100%。

## 账号全局背景

在“偏好设置→全局背景→更换背景”中选择内置背景或上传自己的JPEG、PNG、WebP图片，可调整柔化程度、预览和恢复默认。保存后当前页面立即更新，首页、事项、日历、复盘、设置等登录后页面共享该账号的背景；卡片和编辑面板保留清晰底色。

每个账号的选择与上传独立，登录及注册页不显示个人壁纸。每个账号最多保留一张自定义图片；切换内置背景仍可保留上传，显式移除并保存才会删除。上传原图最大10MB，浏览器压缩后由服务端重新编码；图片随数据库备份。

内置照片来自Unsplash并随应用本地提供，渐变背景为自制图案；不需要访问外部图片站。

## 安装与升级

新用户按[安装指南](INSTALL.md)部署`0.1.0-beta.2`。已有`0.1.0-beta.1`用户请按[升级说明](MAINTENANCE.md#升级到-beta2)备份并保留原项目的数据与密钥。镜像仅提供`linux/amd64`；不支持ARM。功能范围以当前社区版本为准，不包含平台管理后台或Pro专属权益。
